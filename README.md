# ЗАРЯ — украшения в русском стиле

Простой конверсионный сайт-магазин на Flask: тёмный «осенний» дизайн, карточки
товаров, лайки, корзина и поиск. Без базы данных — данные товаров лежат в
`products.py`, а корзина и избранное хранятся в браузере (localStorage).

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Сайт откроется на http://127.0.0.1:5000

## Что внутри

- Главная с подборкой из 7 товаров, hero-блоком и CTA.
- Каталог с фильтром по категориям.
- Страница товара: описание, характеристики, похожие украшения.
- Поиск по названию и описанию.
- Корзина: количество, удаление, бесплатная доставка от 5 000 ₽, демо-оформление.
- Личный кабинет (демо-форма входа).
- Лайки и корзина сохраняются в localStorage.
- Адаптив под телефон, планшет и компьютер, анимации с учётом
  `prefers-reduced-motion`.

## Структура

```
app.py                  маршруты Flask
products.py             список товаров
templates/              HTML-шаблоны (Jinja)
static/css/style.css    все стили
static/js/main.js       вся интерактивность
static/img/*.jpg        фотографии товаров (сгенерированы ИИ)
static/img/favicon.svg  иконка сайта
```

## Откуда фото

Фотографии товаров сгенерированы в бесплатном ИИ-генераторе изображений
(Pollinations). Их можно заменить на свои: положите файлы с теми же именами
в `static/img/` или укажите новые пути в `products.py`.

## Где менять товары

Откройте `products.py` и отредактируйте список `PRODUCTS`: название, цена,
категория, материал, описание и путь к картинке. Новые товары автоматически
появятся в каталоге и поиске.
